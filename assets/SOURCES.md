# Asset sources

- `trustmed-flow.png` and `automation-flow.png`: AI-generated illustrations created for this profile. They are conceptual workflow artwork, not application screenshots.
- `american-football.svg` and `section-mark.svg`: Tabler Icons (MIT), recolored for the profile. Original paths: https://github.com/tabler/tabler-icons/tree/main/icons/outline . The license is included in `tabler-icons-LICENSE.txt`.
- `hero-*.svg` and `hero-mobile-*.svg`: the profile's existing Instrument Serif / Geist font assets and knowledge-graph illustration, adapted by `scripts/build_assets.py` for the open header and narrow screens.
